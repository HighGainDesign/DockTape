# Contributing to DockTape

Contributions are welcome, whether you're reporting a bug, suggesting a feature, improving documentation, or submitting a fix.

## Issues

Search the [existing issues](https://github.com/HighGainDesign/DockTape/issues) before opening a new one. For bugs, include your DockTape and macOS versions, HiDock model if relevant, steps to reproduce, and what you expected versus what happened. For feature requests, describe the problem you'd like to solve.

## Pull requests

Pick an existing issue or open one to discuss a substantial change before starting. Fork the repository, make a focused change on a branch, and [open a pull request](https://github.com/HighGainDesign/DockTape/compare) linking the relevant issue.

Explain what changed and how you verified it. Run the tests relevant to your change; core tests use `swift test`. For app changes, include any manual checks and relevant regression results. The Xcode project is generated from `project.yml`, so change that file rather than the generated project.

Keep private recordings, transcripts, API keys, and signing credentials out of issues and pull requests. Use synthetic or anonymized examples when needed.
