# DockTape

A native macOS app for managing recordings from your [HiDock](https://hidock.com) device.

Import recordings, turn conversations into searchable transcripts, and create summaries. Transcription and speaker identification run on your Mac; optional summaries use your choice of cloud or local AI provider.

## Features

- Import HiDock recordings over USB and play them at adjustable speeds.
- Transcribe audio locally and identify different speakers.
- Create summaries with built-in or custom templates using Anthropic, OpenAI, OpenRouter, or local models.
- Organize recordings into folders, search your library, and merge recordings.
- Store your library in iCloud Drive, locally, or in a folder you choose.
- Export transcripts and summaries, including Markdown, plain text, and subtitles.

## Download

[Download DockTape](https://github.com/HighGainDesign/DockTape/releases/latest) as a signed DMG. Open it and drag DockTape to Applications.

## Requirements

- macOS 14 (Sonoma) or later and an Apple Silicon Mac.
- A HiDock P1, P1 Mini, H1, or H1E connected over USB to import recordings. Hardware testing so far has been with the P1.
